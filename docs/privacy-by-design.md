# Privacy By Design

HPIS applies these demonstration principles:

- Synthetic data only
- Data minimization
- Purpose limitation
- Pseudonymized person identifiers by default
- Least-privilege role access
- Emergency privacy mode for higher-risk conditions
- Retention states for active, archived and deletion-review records
- Audit trails for sensitive access
- Responsible AI that only assists human review

This is not an official ICRC privacy model. It is an independent portfolio-level demonstration inspired by publicly available humanitarian data-protection principles.
